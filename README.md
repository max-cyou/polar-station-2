# Polar Station 2

Веб-панель для Яндекс Станции 2: музыка, громкость, подсветка, системная информация, файлы, процессы и терминал.

## Требования

- Яндекс Станция 2 с root-доступом по SSH и доступом к файлам штатной системы. На обычную колонку без root панель **не устанавливается.**
- Компьютер с Linux, Node.js 22.12+ и npm, Go 1.24+, Git, и SSH.
- Компьютер и колонка в одной сети. Для авторизации и работы с музыкой колонке нужен доступ в интернет и последующая авторизация после установки панели.

Фронтенд встраивается в Go-бинарник. На колонку устанавливать Node.js, npm или Go не нужно.

## Установка

### 1. Скачайте проект

На компьютере:

```sh
git clone https://github.com/max-cyou/polar-station-2.git
cd polar-station-2
npm ci
```

Задайте адрес колонки и SSH-порт. Ниже — пример, замените значения своими:

```sh
STATION_HOST=192.168.1.200
STATION_PORT=2222
```

Проверьте вход:

```sh
ssh -p "$STATION_PORT" "root@$STATION_HOST"
```

После входа выполните `exit`, чтобы вернуться на компьютер.

### 2. Сохраните оригиналы подсветки (!!!)

Перед первым изменением цветов сохраните штатные анимации. Файл `volume.original.led` нужен панели для формирования палитры громкости. Если подсветка уже модифицирована, используйте сохранённые оригиналы своей прошивки.

Запустите на компьютере:

```sh
ssh -p "$STATION_PORT" "root@$STATION_HOST" 'sh -s' <<'REMOTE'
set -eu
base=/data/opt/polar
patterns=/system/vendor/quasar/ledpatterns/panel
mkdir -p "$base/mode-pattern-originals"
if [ ! -f "$base/volume.original.led" ]; then
  cp "$patterns/volume.led" "$base/volume.original.led"
fi
for name in candle.led night_light.led lavalamp.led; do
  if [ ! -f "$base/mode-pattern-originals/$name" ]; then
    cp "$patterns/$name" "$base/mode-pattern-originals/$name"
  fi
done
chmod 600 "$base/volume.original.led" "$base/mode-pattern-originals/"*.led
REMOTE
```

Повторный запуск этой команды сохраняет существующие резервные копии. При последующих изменениях физических палитр Polar также создаёт файлы `backup-*.led` в своём каталоге.

### 3. Соберите и загрузите панель

```sh
sh scripts/deploy.sh "root@$STATION_HOST" "$STATION_PORT"
```

Скрипт соберёт фронтенд и Linux ARM64-бинарник, передаст его по SSH, сверит SHA-256 и запустит панель на порту `8080`. При обновлении он остановит предыдущий экземпляр Polar по сохранённому PID.

Передача работает через SSH без SFTP: устанавливать `sftp-server` или `scp` на колонку не требуется.

Откройте в браузере:

```text
http://{IP СТАНЦИИ}:8080
```

Используйте свой IP колонки. Для музыки нажмите кнопку авторизации в музыкальном блоке и войдите по QR-коду в аккаунт Яндекса, к которому привязана станция.

## Установка автозапуска

После установки панели запустите на компьютере из каталога проекта:

```sh
sh scripts/install-autostart.sh "root@$STATION_HOST" "$STATION_PORT"
```

Скрипт установит службу `/etc/init.d/S99zzpolar`: она запускает Polar при загрузке колонки и останавливает при выключении. Если панель уже работает, второй экземпляр не создаётся. Если не работает — скрипт запустит её сразу.

Перед записью сохраняется резервная копия предыдущего init-скрипта в `/data/opt/polar/backup-autostart-*`. Если корневая файловая система была read-only, установщик временно разрешит запись и вернёт read-only после установки.

Управление службой с компьютера:

```sh
ssh -p "$STATION_PORT" "root@$STATION_HOST" '/etc/init.d/S99zzpolar status'
ssh -p "$STATION_PORT" "root@$STATION_HOST" '/etc/init.d/S99zzpolar restart'
ssh -p "$STATION_PORT" "root@$STATION_HOST" '/etc/init.d/S99zzpolar stop'
ssh -p "$STATION_PORT" "root@$STATION_HOST" '/etc/init.d/S99zzpolar start'
```

Лог находится в `/data/opt/polar/polar.log`. Сам `deploy.sh` автозапуск не устанавливает; после его настройки обычное обновление панели сохраняет службу.

## Обновление

На компьютере, в каталоге проекта:

```sh
git pull --ff-only
npm ci
sh scripts/deploy.sh "root@$STATION_HOST" "$STATION_PORT"
```

Если открыли новый терминал, снова задайте `STATION_HOST` и `STATION_PORT`. Настройки, авторизация и резервные копии в `/data/opt/polar` сохраняются при обновлении.

## Применение цветов

«Сохранить» записывает настройки без перезапуска службы Алисы. Если изменились физические палитры, появится «Применить сейчас»: после подтверждения панель перезапустит `maind`, чтобы он перечитал анимации. Музыка и ответы могут ненадолго прерваться.

Можно сохранить настройки и применить их при следующей перезагрузке колонки. Частые перезапуски ограничены штатным супервизором: при необходимости кнопка покажет время ожидания. Яркость применяется сразу.

## Файлы панели

В `/data/opt/polar` находятся:

| Файл | Назначение |
| --- | --- |
| `polar` | Сервер со встроенным фронтендом |
| `polar.pid`, `polar.log` | PID и лог запущенной панели |
| `auth.json` | Данные авторизации Яндекса; не публикуйте этот файл |
| `lighting.user.json` | Сохранённые настройки подсветки |
| `volume.original.led` | Оригинальная анимация громкости |
| `mode-pattern-originals/` | Оригинальные анимации режимов |
| `backup-*.led` | Копии анимаций перед изменениями |
